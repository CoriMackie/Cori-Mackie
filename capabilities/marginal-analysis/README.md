# Marginal Analysis — Perfect Competition Planting Decision

A constrained-optimization model of a 1.5-acre market garden's planting
mix (tomatoes, carrots, mesclun) under perfect competition: rising
marginal cost per bed (diminishing returns to labor) meeting a flat,
market-given price, subject to a 64-bed cap and a 4-worker labor budget.

- [`spec.md`](spec.md) — the model specification (inputs, structure,
  calculation logic, validation rules, outputs), written before the
  workbook and binding on the build.
- `model.xlsx` — the Excel Solver workbook built from the spec.

See [AGENTS.md](../../AGENTS.md) for how this capability fits the
repo's brief → build → decision convention.
